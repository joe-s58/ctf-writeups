# ctf-writeups

My personal collection of Capture The Flag (CTF) write-ups, notes, and lessons learned.

Each writeup documents how I approached a challenge: the reconnaissance, the vulnerability, the exploitation steps, and what I took away from it. The goal is to build a searchable reference for myself and to help others learning offensive security.

## Repository Layout

Write-ups are organized by the platform or site where the challenge was completed. Each platform gets its own folder, and each folder has its own README describing its contents.

```
ctf-writeups/
├── README.md
└── HackerDNA/        # Labs and challenges from HackerDNA
    ├── CTF/
    └── JWT/
```

| Folder | Platform | Description |
|--------|----------|-------------|
| [HackerDNA](./HackerDNA) | HackerDNA | Hands-on labs and CTF-style challenges |

More platforms will be added as sub-folders over time.

## What a Write-up Contains

- **Overview**: what the challenge is and what it teaches
- **Recon**: how the target was explored and enumerated
- **Exploitation**: the steps taken, with commands and explanations
- **Takeaways**: the concept learned and how to defend against it

## Notes

Flags and solutions for active or competitive events are not published. Write-ups cover retired or practice challenges only. All notes and Information are my own summaries. There is no exam questions, and no copyrighted course material is included.

## Disclaimer

All content here relates to intentionally vulnerable labs and CTF environments where testing is explicitly permitted. Do not use these techniques against systems you do not own or have written authorization to test.
