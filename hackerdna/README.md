# HackerDNA - Challenges

Write-ups for labs and challenges completed on [HackerDNA](https://hackerdna.com), a hands-on cybersecurity training platform.

## Contents

| Folder | Purpose |
|--------|---------|
| [ctf-challenges](./ctf-challenges) | General CTF-style labs: multi-step machines and applications where the goal is to find flags through enumeration, exploitation, and privilege escalation |
| [jwt-privilege-escalation](./jwt-privilege-escalation | Labs focused on JSON Web Token security: token tampering, weak secrets, algorithm confusion, and role-based privilege escalation |

## Notes

Flags and solutions for active or competitive events are not published. Write-ups cover retired or practice challenges only. All notes and Information are my own summaries. There is no exam questions, and no copyrighted course material is included.

## Disclaimer

All content here relates to intentionally vulnerable labs and CTF environments where testing is explicitly permitted. Do not use these techniques against systems you do not own or have written authorization to test.
